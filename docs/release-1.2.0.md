# 1.2.0：Table 模型

新增 Table 勾選項目及狀態卡片，GUI、背景命令、既有排程、登入後繼續、最後總結、失敗重試和續跑均使用同一套模型清單。保留舊版執行檔，新版另存為 `LietaAutomator_1.2.0.exe`。

## 操作與存放

- 使用原本的 ticker 清單及目的地，勾選 Table 後開始。升級不會擅自變更既有勾選；續跑舊批次也不會加入新模型。
- HTML 存入 `目的地/Table/TICKER/YYYY-MM-DD_HH;MM_TICKER_Table.html`，例如 `Table/NVDA/2026-10-04_09;09_NVDA_Table.html`。不加入秒數、亂數或其他檔名後綴，保留下載內容。
- 全選五模型可使用五個視窗，等待上限預設仍為 1；共用至少 5 秒提交間隔及原本的冷卻、補抓規則。第五個 Profile 使用 9226，首次使用可能需要登入。
- 保留單視窗模式。Table 也可透過 `--models Table` 單獨執行。

## Table 判定方式

實際 Table 匯出是 Plotly table，沒有 ticker 標題。逐筆開始前會重載該視窗並重新選模型，避免沿用前一筆無標題的表格；提交後確認目前模型、輸入 ticker、新結果及穩定狀態。下載後解析 Plotly 的表頭和資料列，也支援原生 HTML table，拒絕空表或不完整欄位。

HTML 原始內容不改寫。因匯出本身不含 ticker，資料歸屬依據獨立頁面上的本次請求，不能單靠檔案內容再次核對 ticker；續跑仍會核對原存檔雜湊值。
