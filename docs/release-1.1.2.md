# 1.1.2：結束摘要與重試失敗項目

- 「開始下載」正下方新增「重試失敗項目」。目前批次結束後直接重試該批次；程式重新開啟時可選擇舊批次 JSON。
- 使用原清單、模型與目的地重新驗證成功檔案，只提交未完成或已損壞／遺失的模型與 ticker 配對。已成功項目不重新請求。
- 每次手動重試仍採等待上限 1、5 秒共用間隔、原冷卻及有限補抓規則。
- 最後總結列出成功／總數、各模型未完成 ticker 與最後原因，同時寫入日誌及批次 JSON 的 `summary`。登入等待尚未結束，不先產生最終結論。
- Try Again 重試用盡與 90 秒逾時使用不同錯誤文字。

舊版日誌裡的「延後補抓」只表示某一輪失敗，不能直接視為最終失敗。最終結論應以批次及單模型紀錄為準。
